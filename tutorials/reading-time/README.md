# Article Summarizer - Gemini

A Chrome extension that helps you read more efficiently by providing quick article summaries and estimated reading times.

## 🌟 Features

- Automatically generates concise summaries under article titles
- Estimates reading time for articles
- Helps readers quickly evaluate content relevance
- Clean and unobtrusive interface
- Free during beta testing phase

## 🔗 Links

- [Chrome Web Store](https://chromewebstore.google.com/detail/article-summarizer-gemini/oecbijpehffenacbeabefgdcmbnehakf?hl=en)
- [Official Website](https://www.articlesummarizer-gemini.xyz/)

## 💡 How It Works

The extension automatically analyzes webpage content and provides two key pieces of information:
1. A brief summary of the article content
2. Estimated reading time

This helps users make quick decisions about whether to invest time in reading the full article.

## 🚀 Installation

1. Visit the [Chrome Web Store page](https://chromewebstore.google.com/detail/article-summarizer-gemini/oecbijpehffenacbeabefgdcmbnehakf?hl=en)
2. Click "Add to Chrome"
3. Follow the installation prompts
